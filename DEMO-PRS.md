## PR #4 — комментарии к статьям и импорт из YAML (Python)

| # | Класс | Где | Дефект |
|---|---|---|---|
| 1 | Секреты | `comments.py`, `JWT_SECRET` | секрет JWT прямо в коде |
| 2 | Безопасность | `list_comments` | SQL-инъекция через f-строку |
| 3 | Логика | `list_comments` | `start = page * PAGE_SIZE`: при `page=1` первые 20 комментариев пропадают |
| 4 | Логика | `add_comment` | пользователь не найден (`None`) → 500 вместо 401 |
| 5 | Безопасность | `delete_comment` | перевёрнута проверка прав: не-админ удаляет чужие комментарии, админ получает 403 |
| 6 | Логика | `delete_comment` | комментарий не найден → 500 вместо 404 |
| 7 | Безопасность | `import_comments` | `yaml.load` без `SafeLoader`: небезопасная десериализация |
| 8 | Безопасность | `requirements.txt` | `PyYAML==5.3` с известными CVE |
| 9 | Тесты | весь PR | новая логика без тестов |

## PR #5 — лента статей (TypeScript)

| # | Класс | Где | Дефект |
|---|---|---|---|
| 1 | Секреты | `ANALYTICS_API_KEY` | ключ в коде, к тому же уходит третьей стороне в query-строке |
| 2 | Безопасность | `readSettings` | `lodash.merge` объекта из URL → prototype pollution |
| 3 | Безопасность | `package.json` | `lodash 4.17.15`, `marked 0.3.6` с известными CVE |
| 4 | Логика | `formatDate` | `getMonth()` с нуля: январь показывается как 0 |
| 5 | Логика | `totalPages` | `Math.floor` вместо `Math.ceil`: последняя страница теряется |
| 6 | Логика | `isOwnArticle` | `user` может быть `undefined` → TypeError у гостя |
| 7 | Безопасность | `renderFeed` | `innerHTML` с заголовком и автором → XSS |
| 8 | Безопасность | `renderFeed` | Markdown без санитизации → XSS |
| 9 | Тесты | `format.test.ts` | тест отключён через `test.skip` |
